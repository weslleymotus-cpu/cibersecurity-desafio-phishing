# Desafio de Projeto - Simulação Educacional de Phishing

## Descrição

Projeto desenvolvido como parte da formação em Cybersecurity da DIO.

O objetivo é demonstrar, em ambiente controlado e exclusivamente educacional, como técnicas de engenharia social podem induzir usuários a interagir com páginas falsas.

Esta versão foi desenvolvida com foco em conscientização. Nenhuma credencial é armazenada, transmitida ou registrada.

## Objetivos

- Compreender conceitos de phishing e engenharia social;
- Demonstrar os riscos de páginas falsas;
- Desenvolver uma visão defensiva sobre segurança da informação;
- Praticar documentação e versionamento utilizando Git e GitHub.

## Funcionamento da demonstração

A aplicação apresenta uma tela fictícia de login para fins de treinamento.

Ao tentar enviar o formulário:

1. Nenhuma informação é enviada para um servidor;
2. Nenhuma senha é armazenada;
3. A página exibe uma mensagem educativa;
4. O usuário recebe orientações para identificar tentativas de phishing.

## Principais aprendizados

- Phishing explora confiança, urgência e distração;
- URLs devem ser verificadas antes do login;
- Autenticação multifator ajuda a reduzir riscos;
- Senhas não devem ser reutilizadas;
- Usuários devem desconfiar de solicitações inesperadas.

## Como executar

Clone o repositório:

```bash
git clone https://github.com/SEU-USUARIO/cibersecurity-desafio-phishing.git
```

Entre na pasta:

```bash
cd cibersecurity-desafio-phishing
```

Abra o arquivo `index.html` no navegador.

## Prevenção contra phishing

- Verifique o endereço do site;
- Desconfie de mensagens urgentes;
- Não compartilhe senhas;
- Utilize MFA;
- Use gerenciadores de senha;
- Mantenha sistemas atualizados;
- Confirme solicitações por canais oficiais.

## Aviso ético

Este projeto possui finalidade exclusivamente educacional e de conscientização em segurança da informação.

Não deve ser utilizado para coleta de credenciais reais ou atividades não autorizadas.
